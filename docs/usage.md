# Usage Guide

## Prerequisites
This project assumes you have run either PyRadiomic or Foundation Model for Cancer Image Biomarkers (FMCIB) feature extraction on your images. The output of this should be a `.csv` file where:  
* Each row contains data for a single region of interest (ROI)
* The first column is a sample identifier (e.g. SampleID, PatientID)
